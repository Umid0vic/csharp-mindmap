# C# Interactive Mind Map

An interactive mind map for exploring C# concepts through visual connections, short explanations, and practical code examples.

Built with **HTML, CSS, JavaScript, and SVG**, without external frameworks or dependencies.

## Features

- **Interactive Mind Map** – Explore C# topics through connected, expandable branches.
- **Code Examples** – View explanations and practical C# examples for each topic.
- **Search** – Quickly find specific concepts.
- **Zoom & Pan** – Navigate the mind map freely.
- **Dark Mode** – Switch between light, dark, and system themes.
- **Responsive Design** – Works on desktop and mobile devices.
- **Offline Support** – Runs locally without an internet connection.

## Topics Covered

- C# Type System
- Statements and Control Flow
- Operators and Expressions
- Collections and Generics
- LINQ

## Getting Started

Visit the [Live Demo](https://Umid0vic.github.io/csharp-mindmap/) or download the repository and open `index.html` in your browser.

No installation or build process is required.
